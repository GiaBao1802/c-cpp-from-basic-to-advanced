# Professional curriculum — 24 tuần

Mỗi tuần 10–12 giờ. Nếu chỉ đọc mà không làm deliverable, không tính hoàn thành.

| Tuần | Chủ đề | Deliverable |
|---:|---|---|
| 1–2 | Modern C++, ownership, STL, build | refactor module + tests |
| 3 | concurrency, bounded queue, shutdown | stress-tested pipeline |
| 4 | Linux/IPC/debug/profiling | daemon + latency report |
| 5–6 | vehicle coordinate, units, kinematics | bicycle simulation plot |
| 7–8 | longitudinal dynamics, PID | speed controller + KPIs |
| 9–10 | ACC gap control, state/override | lead/cut-in scenarios |
| 11–12 | lateral dynamics/control | lane-centering scenarios |
| 13 | sensors, timestamps, validity | synchronization buffer |
| 14 | fusion/target selection basics | multi-object association stub |
| 15 | CAN/FlexRay/Ethernet/XCP | interface/latency design |
| 16 | AUTOSAR/RTE/OS/COM/DEM | deployment mapping |
| 17 | gTest and test design | parameterized suite |
| 18 | Python/MATLAB simulation analysis | automated KPI report |
| 19 | SIL campaign | scenario matrix/results |
| 20 | HIL architecture/fault injection | HIL test specification |
| 21 | ASPICE requirements/architecture | bidirectional trace matrix |
| 22 | ISO 26262/SOTIF basics | safety analysis exercise |
| 23 | estimation/review/defect | review + defect RCA package |
| 24 | capstone defense/interview | demo, design defense, CV pitch |

## Weekly routine

Theory 25%, implementation 35%, testing/simulation 25%, explanation/review 15%. Mỗi feature phải đi qua requirement → design → implementation → test → evidence.
